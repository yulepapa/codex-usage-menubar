# Codex Usage Menu Bar

**Codex 사용량을 Mac 메뉴바에서 확인하고, 리셋권의 만료를 놓치지 않도록 돕는 앱입니다.** 조건이 맞으면 리셋권을 자동으로 사용할 수도 있습니다. 현재 앱 버전은 **1.1.3**입니다.

## 이런 분께 유용합니다

- Codex를 쓰면서 5시간·주간 사용량이 얼마나 남았는지 자주 확인하는 분
- 리셋권을 가지고 있지만 만료 시기를 잊기 쉬운 분
- 기존 리셋 감시 프로그램의 상태를 메뉴바에서 함께 보고 싶은 분

리셋권이 없어도 사용량 확인 기능은 사용할 수 있습니다.

## 설치하고 실행하기

### 1. 준비하기

**macOS 13 이상**과 설치·로그인이 완료된 **Codex CLI**가 필요합니다. Codex CLI는 터미널에서 사용하는 Codex 프로그램입니다. 아직 없다면 [공식 설치 안내](https://learn.chatgpt.com/docs/codex/cli)를 먼저 확인하세요.

터미널에서 다음 명령으로 설치와 로그인 상태를 확인합니다.

```sh
codex --version
codex login status
```

처음 앱을 설치할 때는 Mac에서 앱을 만드는 도구인 **Xcode Command Line Tools**도 필요합니다. 설치되어 있지 않다면 다음 명령을 실행하고 화면 안내를 따릅니다.

```sh
xcode-select --install
```

### 2. 사용량 표시 앱 설치하기

아래는 **리셋 자동 사용을 아직 설정하지 않은 Mac**에서 처음 설치하는 순서입니다.

```sh
git clone https://github.com/yulepapa/codex-usage-menubar.git
cd codex-usage-menubar
make test
./Scripts/install.sh
```

`make test`는 가상 자료로 코드를 검사하며 실제 리셋권을 사용하지 않습니다. 설치 명령은 앱을 만들고 `~/Applications/CodexUsage.app`에 설치한 뒤 실행합니다. 이후 Mac에 로그인하면 메뉴바 앱이 자동으로 열립니다.

설치는 끝났는데 아이콘이 보이지 않으면 Finder에서 사용자 폴더의 **응용 프로그램 → CodexUsage.app**을 열어 보세요. 메뉴바를 정리하는 앱을 쓰고 있다면 숨김 영역도 확인합니다.

**이 설치만으로 리셋권 자동 사용이나 만료 알림을 담당하는 감시 프로그램이 등록되지는 않습니다.** 이미 자동 사용을 설정한 Mac에서는 위 설치 명령을 다시 실행하지 말고, 기존 설치 때 사용한 업데이트·복구 방법을 따르세요.

### 3. 자동 사용과 알림 설정하기

자동 사용과 만료 알림에는 앱을 닫아도 동작하는 **백그라운드 감시 프로그램**이 필요합니다.

현재 제공하는 설정 도구는 기존 Python 감시기(`reset_credit_watcher.py`)를 이 앱으로 옮기는 용도입니다. 기존 감시기가 없는 Mac에 새 감시기를 처음 등록하는 절차는 제공하지 않습니다. 해당하는 경우 [기존 감시기 연결 안내](Docs/ADVANCED.md#기존-감시기를-앱으로-옮기기)를 확인하세요.

감시기 설정이 끝났다면 메뉴에서 다음 두 항목을 각각 선택할 수 있습니다.

- **자동 사용 켜짐/꺼짐:** 조건을 만족하면 리셋권을 실제로 사용합니다.
- **상세 → 만료 전 Mac 알림:** 리셋권 만료 전에 알림을 보냅니다.

자동 사용을 끄고 알림만 켜 두는 것도 가능합니다. 알림을 받으려면 **시스템 설정 → 알림 → CodexUsage**에서 알림을 허용하세요.

## 메뉴바에서 사용하는 방법

메뉴바의 Codex 아이콘을 클릭하면 **남은 사용량**, **리셋권 수와 만료 시각**, **자동 사용 상태**가 보입니다.

**상세**에는 사용량이 다시 채워지는 시각, 다음 자동 사용 시도 시각, 최근 처리 결과와 알림 설정이 있습니다. 표시된 시도 시각은 조건이 맞을 때의 예정이며, 실행을 보장하지 않습니다. **새로고침**을 누르면 사용량을 다시 확인합니다. 기본 갱신 간격은 5분이며, Mac이 잠자기에서 깨어날 때도 갱신합니다.

| 표시 | 뜻 |
| --- | --- |
| `주간 남음 60%` 등 | 해당 기간에 사용할 수 있는 양이 60% 남았다는 뜻입니다. Codex가 제공하는 구간별로 표시합니다. |
| `리셋권 2장` 등 | 최신 조회에서 확인한 사용 가능한 리셋권 수입니다. |
| `만료` | 가장 먼저 만료되는 권의 기한입니다. 날짜와 시간은 Mac의 시간대를 따릅니다. |
| `…` | 처음 사용량을 확인하고 있습니다. |
| `!` 또는 `?` | 조회에 실패했거나 정보를 확인할 수 없습니다. 사용량을 다 썼다는 뜻은 아닙니다. |
| `소비 결과 확인 필요 · 추가 사용 보류` | 사용 요청의 결과를 아직 확인하지 못해 다른 리셋권을 더 쓰지 않고 기다립니다. |

만료가 가깝거나 로그인·감시 프로그램·알림에 문제가 있으면 첫 화면에 짧은 안내가 추가됩니다.

## 리셋권 자동 사용과 알림은 어떻게 다른가요?

**리셋권**은 Codex에서 제공하는 사용량 초기화 권리입니다. 만료 기한이 지나면 사용할 수 없습니다.

앱은 다음 조건이 **모두 맞을 때만** 자동 사용을 시도합니다.

1. 감시 프로그램이 정상 실행 중이고 **자동 사용**이 켜져 있습니다.
2. 리셋권이 아직 유효하며 **만료까지 20분 이하**입니다.
3. **기본 Codex의 5시간 또는 주간 남은 사용량이 10% 이하입니다.**
4. 사용 직전에 다시 확인해도 같은 권과 만료 시각, 사용량 조건이 맞습니다.

예를 들어 만료가 15분 남았어도 사용량이 넉넉하면 자동으로 쓰지 않습니다. 별도 기능의 사용량 제한은 이 판단에 사용하지 않으며, 최종 사용 가능 여부와 결과는 Codex 서비스가 결정합니다.

감시 프로그램은 Mac이 깨어 있는 동안 1분마다 확인합니다. 따라서 ‘20분 전’은 정확한 예약 시각이 아니라 자동 사용을 시도할 수 있는 범위입니다.

**만료 알림은 자동 사용 여부와 별개입니다.** 알림을 켜 두면 만료 **1시간·20분·5분 전**에 알려 줍니다. 사용량이 넉넉하거나 다른 권의 사용 결과를 확인하는 중이어도, 조회에서 확인된 사용 가능한 권의 알림은 처리합니다. 알림이 왔다고 리셋권이 사용됐다는 뜻은 아닙니다.

## 꼭 알아둘 점

- **Mac이 켜져 있고 로그인되어 있어야 합니다.** 전원이 꺼져 있거나 잠든 동안에는 확인·사용·알림을 실행할 수 없습니다. 앱이 Mac을 자동으로 깨우지는 않습니다.
- **메뉴의 종료는 감시 프로그램을 멈추지 않습니다.** 자동 사용을 멈추려면 먼저 메뉴에서 자동 사용을 끄세요.
- **결과가 불확실하면 다른 권의 새 사용을 보류합니다.** 재시작해도 이 상태를 유지하며, 권이 사라졌다고 성공으로 판단하지 않습니다. 사용 기록을 지우거나 감시 프로그램을 두 개 실행하지 마세요.
- **이미 만료된 권을 나중에 되살리지는 못합니다.** 잠자기에서 깨어난 뒤에는 현재 시점에 맞는 알림을 보내며, 놓친 단계의 알림을 한꺼번에 보내지 않습니다.
- **알림이 허용돼 있어도 집중 모드나 배너 설정 때문에 화면에 안 보일 수 있습니다.**
- **로그인 정보와 실제 사용 기록은 공개하지 마세요.** 앱은 기존 Codex CLI 로그인을 이용하며 로그인 파일·쿠키·토큰을 직접 읽거나 복사하지 않습니다. 사용량을 자체 서버나 제3자에게 보내지 않고, 새로운 AI 대화를 시작하지도 않습니다.

백업에서 이전 앱을 복원할 때도 현재 사용 기록을 보존해야 합니다. 자세한 절차는 [백업과 복구](Docs/ADVANCED.md#백업과-복구)를 참고하세요.

## 문제가 생기면

| 증상 | 먼저 확인할 것 |
| --- | --- |
| 아이콘이 보이지 않음 | CodexUsage.app을 직접 열고, 메뉴바 관리 앱의 숨김 영역을 확인하세요. |
| `!`, `?` 또는 오래된 사용량 | Codex CLI의 설치·로그인과 네트워크를 확인한 뒤 **새로고침**을 누르세요. |
| 자동 사용을 켤 수 없음 | 백그라운드 감시 프로그램의 설정이 완료됐는지 확인하세요. |
| 자동으로 사용되지 않음 | 자동 사용이 켜져 있는지, 만료 20분 이내인지, 5시간 또는 주간 남은 사용량이 10% 이하인지 확인하세요. |
| 결과 확인 필요 | 사용 기록을 보존하고 [자세한 점검 안내](Docs/ADVANCED.md#상태-점검)를 확인하세요. 기록 삭제나 재설치로 해결하려 하지 마세요. |
| 알림이 안 보임 | 시스템 설정의 CodexUsage 알림 허용, 배너와 집중 모드를 확인하세요. |
| 설치 명령이 감시기 설정을 발견하고 중단함 | 기존 자동 사용 설정을 보호하기 위한 동작입니다. 기존 설치 때 사용한 업데이트·복구 절차를 따르세요. |

더 자세한 설정, 점검 명령, 백업·복구와 개발용 메뉴 미리보기는 [자세한 설정·개발 안내](Docs/ADVANCED.md)에 정리했습니다. 실제 리셋권 사용·만료 배너·재부팅 후 동작·운영 복구를 모두 시험한 것은 아닙니다. 확인된 범위는 [검증 문서](Docs/VALIDATION.md)를 참고하세요.
