# Codex Usage Menu Bar

**Codex 사용량과 리셋권을 Mac 메뉴바에서 확인하고, 조건이 맞으면 리셋권을 자동으로 사용하는 앱입니다.**

현재 버전: **1.1.3** · macOS 13 이상

## 메뉴바에서 확인하기

Codex 아이콘을 클릭하면 다음 정보가 보입니다. 리셋권이 없어도 사용량 확인은 가능합니다.

| 항목 | 의미와 사용법 |
| --- | --- |
| 남은 사용량 | 5시간·주간 등 Codex가 제공하는 구간별 잔여량입니다. `60%`는 사용할 수 있는 양이 60% 남았다는 뜻입니다. |
| 리셋권 | 사용 가능한 권의 수와 가장 빠른 만료 시각입니다. 날짜는 Mac의 시간대를 따릅니다. |
| 자동 사용 켜짐/꺼짐 | 자동 사용을 켜거나 끕니다. 아래의 감시 프로그램 설정이 필요합니다. |
| 상세 | 사용량이 다시 채워지는 시각, 다음 조건부 시도 시각, 최근 결과와 알림 설정을 확인합니다. |

사용량은 기본 5분마다, 잠자기에서 깨어날 때 갱신합니다. 바로 확인하려면 **새로고침**을 누르세요.

## 설치·시작

**자동 사용·만료 알림 연결은 기존 Python 감시 프로그램(`reset_credit_watcher.py`)이 있는 경우에만 지원합니다.** 기존 감시 프로그램이 없는 Mac에 새로 등록하는 절차는 제공하지 않습니다.

### 사용량 표시 앱 설치

설치·로그인이 완료된 **Codex CLI**(터미널에서 쓰는 Codex 프로그램)가 필요합니다. 없다면 [공식 설치 안내](https://learn.chatgpt.com/docs/codex/cli)를 먼저 확인하세요.

```sh
codex --version
codex login status
```

앱을 만드는 도구인 **Xcode Command Line Tools**가 없다면 다음 명령으로 설치합니다.

```sh
xcode-select --install
```

아래는 **앱의 감시 프로그램을 아직 연결하지 않은 Mac**에서 사용량 표시 앱을 처음 설치하는 순서입니다.

```sh
git clone https://github.com/yulepapa/codex-usage-menubar.git
cd codex-usage-menubar
make test
./Scripts/install.sh
```

`make test`는 가상 자료를 검사하며 실제 리셋권을 사용하지 않습니다. 설치 명령은 앱을 만들어 `~/Applications/CodexUsage.app`에 넣고 실행하며, 다음 Mac 로그인부터도 자동으로 엽니다.

**이 설치만으로 자동 사용과 만료 알림이 활성화되지는 않습니다.** 앱의 감시 프로그램이 이미 연결돼 있다면 일반 설치 명령이 중단되므로, 기존 업데이트·복구 절차를 사용하세요.

### 자동 사용·알림 연결

두 기능은 앱을 닫아도 실행되는 **백그라운드 감시 프로그램**이 담당합니다.

해당하는 경우 [기존 감시기 연결 안내](Docs/ADVANCED.md#기존-감시기를-앱으로-옮기기)에 따라 설정하세요. 자동 사용을 멈추려면 메뉴에서 **자동 사용**을 끕니다. **메뉴의 종료는 감시 프로그램을 멈추지 않습니다.**

## 자동 사용 조건

리셋권은 Codex 사용량을 초기화하는 권리이며, 기한이 지나면 사용할 수 없습니다. 감시 프로그램은 **자동 사용이 켜져 있고 다음 조건이 모두 맞을 때** 사용을 시도합니다.

1. 리셋권이 유효하고 **만료까지 20분 이하**입니다.
2. **기본 Codex의 5시간 또는 주간 남은 사용량이 10% 이하**입니다. 별도 기능의 사용량 제한은 판단에 사용하지 않습니다.
3. 사용 직전 재조회에서도 같은 권과 만료 시각, 사용량 조건이 확인됩니다.

**Mac이 깨어 있고 로그인되어 있어야 합니다.** 감시기는 정상 실행 중 1분마다 확인하므로 표시된 예정 시각에 반드시 실행되는 것은 아닙니다. 앱이 Mac을 깨우지는 않으며, 이미 만료된 권을 되살릴 수도 없습니다. 최종 사용 가능 여부와 결과는 Codex 서비스가 결정합니다.

**‘소비 결과 확인 필요 · 추가 사용 보류’가 보이면 사용 결과가 아직 불확실한 상태입니다.** 앱은 재시작 후에도 다른 권의 새 사용을 보류하며, 권이 사라졌다는 이유로 성공을 추정하지 않습니다. 사용 기록을 지우거나 감시 프로그램을 두 개 실행하지 말고 [상태 점검·복구 안내](Docs/ADVANCED.md#상태-점검)를 확인하세요.

### 만료 알림

**상세 → 만료 전 Mac 알림**을 켜면 만료 **1시간·20분·5분 전**에 알립니다. 자동 사용을 꺼 두거나 다른 권의 사용 결과를 확인하는 중에도, 현재 사용 가능한 권의 알림은 처리합니다. 알림 자체는 사용 완료를 뜻하지 않습니다.

잠자기에서 깨어나면 현재 시점에 맞는 알림만 보내며, 놓친 단계의 알림을 한꺼번에 보내지 않습니다.

## 문제가 생기면

| 증상 | 확인할 것 |
| --- | --- |
| 아이콘이 안 보임 | Finder의 사용자 폴더 → 응용 프로그램에서 CodexUsage.app을 열고, 메뉴바 관리 앱의 숨김 영역을 확인하세요. |
| `…`, `!`, `?` 또는 오래된 값 | `…`는 첫 조회 중, `!`는 조회 실패, `?`는 사용량 정보가 없는 상태입니다. 실패가 계속되면 CLI 설치·로그인·네트워크를 확인하고 새로고침하세요. |
| 자동 사용을 켤 수 없거나 사용되지 않음 | [감시기 연결](Docs/ADVANCED.md#기존-감시기를-앱으로-옮기기)과 위의 자동 사용 조건을 확인하세요. |
| 알림이 안 보임 | 시스템 설정 → 알림 → CodexUsage에서 허용하고, 배너 설정과 집중 모드를 확인하세요. |

자세한 설정·진단 명령·개발 방법은 [상세 안내](Docs/ADVANCED.md)에 있습니다. 이전 앱으로 돌아갈 때도 현재 사용 기록을 보존해야 합니다. [백업과 복구](Docs/ADVANCED.md#백업과-복구)를 따르세요.

가상 검사와 실제 환경 검증은 [검증 문서](Docs/VALIDATION.md)에 구분했습니다. 실제 리셋권 사용·만료 배너·재부팅 및 잠자기 복귀·운영 복구는 모두 검증된 상태가 아닙니다.

앱은 기존 Codex CLI 로그인을 이용하며 로그인 파일·쿠키·토큰을 직접 읽거나 복사하지 않습니다. 사용량을 자체 서버나 제3자에게 보내거나 새 AI 대화를 시작하지 않습니다. **로그인 정보·실제 사용 기록·로그·백업은 공개하지 마세요.**
