# Codex Usage Menu Bar

**Codex 사용량과 리셋권을 Mac 메뉴바에서 확인하고, 조건이 맞으면 리셋권을 자동으로 사용하는 앱입니다.**

macOS 13 이상 · 현재 버전 **1.1.4**

## 처음 설치

Mac의 **터미널**에 아래 한 줄을 붙여 넣으세요. 메뉴바 앱과 자동 감시 기능을 함께 설치합니다. 처음이라면 [Codex 로그인·Mac 빌드 도구 준비](Docs/ADVANCED.md#설치-준비)를 먼저 진행하세요.

```sh
git clone https://github.com/yulepapa/codex-usage-menubar.git && cd codex-usage-menubar && ./Scripts/install.sh
```

앱은 사용자 폴더의 **응용 프로그램 → CodexUsage.app**에 설치되며, 다음 Mac 로그인부터 자동으로 열립니다. 이미 설치했다면 [기존 설치 관리](Docs/ADVANCED.md#설치-위치와-갱신-간격)를 참고하세요.

## 첫 사용

1. 메뉴바의 **Codex 아이콘**을 클릭합니다.
2. **남은 사용량**을 확인합니다. `60%`라면 해당 기간에 쓸 수 있는 양이 60% 남았다는 뜻입니다.
3. **상세**에서 사용량이 다시 채워지는 시각과 최근 처리 결과를 확인합니다.

사용량은 기본 5분마다 갱신됩니다. 바로 확인하려면 **새로고침**을 누르세요.

## 리셋권과 만료 알림

계정에 리셋권이 있으면 메뉴에서 보유 수와 만료 시각을 확인할 수 있습니다. 리셋권은 Codex 사용량을 초기화하는 권리입니다.

설치하면 두 기능이 함께 준비됩니다. 처음에는 **자동 사용 꺼짐·만료 알림 켜짐**으로 시작하며, 메뉴에서 각각 바꿀 수 있습니다. 기존 설치를 업데이트하면 현재 선택을 유지합니다.

- **자동 사용:** 켜면 남은 사용량과 관계없이, 유효한 리셋권의 만료까지 **20분 이하**일 때 사용을 시도합니다. 최종 처리 여부는 Codex 서비스가 결정하며, 초기화할 사용량이 없다는 응답은 메뉴에 표시합니다.
- **상세 → 만료 전 Mac 알림:** 켜면 만료 1시간·20분·5분 전에 알립니다. 자동 사용을 끄고 알림만 받을 수도 있습니다.

두 기능은 **Mac이 깨어 있고 로그인된 동안** 동작합니다. 메뉴 앱을 종료해도 감시 프로그램은 계속 실행되므로, 자동 사용을 멈추려면 **자동 사용**을 끄세요.

## 업데이트·제거

최신 소스를 받은 프로젝트 폴더에서 `./Scripts/install.sh`를 다시 실행하면 앱과 감시 기능을 함께 갱신합니다. 제거할 때는 `./Scripts/uninstall.sh`를 실행하세요. 설정과 사용 기록은 재설치·복구를 위해 보관합니다.
