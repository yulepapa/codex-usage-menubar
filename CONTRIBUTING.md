# Contributing

Thanks for helping improve Codex Usage Menu Bar.

## Development

1. Fork and clone the repository.
2. Create a focused branch.
3. Run `make test` before opening a pull request.
4. If you have an authenticated Codex CLI, also run `make test-live`.

Please keep the app dependency-free and avoid reading Codex authentication files directly. New user-facing strings should include both English and Korean variants.

## Pull requests

Describe the problem, the approach, and how you tested the change. Keep unrelated changes in separate pull requests.
